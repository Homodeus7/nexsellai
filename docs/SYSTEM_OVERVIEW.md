# NexSell AI - Обзор системы

## Что это?

**NexSell AI Backend** - это автоматизированная система для продажи доступа к закрытым Telegram каналам.

### Как это работает (простыми словами)

1. **Клиент** выбирает тарифный план на вашем сайте
2. **Система** создает заказ и отправляет клиента на оплату (FreedomPay)
3. **Клиент** оплачивает заказ
4. **FreedomPay** уведомляет систему об успешной оплате
5. **Система** автоматически выдает доступ к Telegram каналу
6. **Клиент** получает уведомление и инвайт-ссылку

Все происходит автоматически, без вашего участия!

---

## Основные возможности

### Для клиентов (публичное API)

- Просмотр доступных тарифных планов
- Создание заказа на покупку доступа
- Оплата через FreedomPay (все популярные способы)
- Проверка статуса заказа
- Автоматическое получение доступа к Telegram каналу

### Для администратора (админ-панель)

- Управление тарифными планами (создание, редактирование, деактивация)
- Просмотр всех заказов и их статусов
- Управление доступами (просмотр, отзыв)
- Статистика продаж и выручки
- Безопасная авторизация через JWT

## Структура данных

### 1. Тарифные планы (Plans)

Каждый план содержит:

- **Название** - например "Базовый", "Премиум"
- **Цена** - стоимость в тенге (KZT) или сомах (KGS)
- **Валюта** - KZT или KGS
- **Длительность** - на сколько дней выдается доступ (30, 90, 365 и т.д.)
- **Описание** - что входит в план
- **Telegram канал** - к какому каналу дается доступ
- **Статус** - активен или нет (можно временно отключать планы)

**Примеры стандартных планов:**

| План | Цена | Длительность | Описание |
|------|------|--------------|----------|
| Базовый | 5 000 KZT | 30 дней | Базовый доступ к материалам |
| Стандарт | 12 000 KZT | 90 дней | Расширенный доступ + бонусы |
| Премиум | 40 000 KZT | 365 дней | Полный доступ на год |

### 2. Заказы (Orders)

Когда клиент хочет купить доступ, создается заказ:

- **Уникальный ID** - для отслеживания
- **Тарифный план** - какой план купили
- **Email клиента** - для уведомлений
- **Telegram клиента** - username или ID для добавления в канал
- **Статус** - pending (ожидает оплату) → paid (оплачен) → completed (доступ выдан) или failed (ошибка)
- **Цена** - сумма заказа
- **Ссылка на оплату** - URL для перехода на FreedomPay
- **Дата создания** - когда был создан заказ

### 3. Доступы (Accesses)

После оплаты создается запись о доступе:

- **К какому заказу относится**
- **Telegram ID пользователя**
- **Какой канал** - ID канала в Telegram
- **Дата начала** - когда выдан доступ
- **Дата окончания** - когда истекает
- **Статус** - active (активен) или revoked (отозван)

### 4. Администраторы (Admins)

Учетные записи для входа в админ-панель:

- **Логин** - имя пользователя
- **Пароль** - хэшированный пароль (bcrypt)
- **Дата создания**

## Процесс покупки (подробно)

### Шаг 1: Выбор тарифа

Клиент заходит на ваш сайт и видит список тарифов.

**API запрос:**
```
GET /api/plans
```

**Ответ:**
```json
[
  {
    "id": 1,
    "name": "Базовый",
    "price": 5000,
    "currency": "KZT",
    "duration_days": 30,
    "description": "Базовый доступ"
  }
]
```

### Шаг 2: Создание заказа

Клиент нажимает "Купить" и заполняет email и Telegram.

**API запрос:**
```
POST /api/orders
{
  "plan_id": 1,
  "customer_email": "user@example.com",
  "customer_tg": "@username"
}
```

**Ответ:**
```json
{
  "order": {
    "uid": "uuid-здесь",
    "status": "pending",
    "total": 5000,
    "currency": "KZT"
  },
  "payment_url": "https://pay.freedompay.kg/payment/..."
}
```

### Шаг 3: Оплата

Клиент переходит по `payment_url` и оплачивает через FreedomPay (карта, кошелек и т.д.)

### Шаг 4: Уведомление об оплате

FreedomPay отправляет webhook на ваш сервер:

```
POST /api/webhooks/freedom
```

Система:
1. Проверяет подпись запроса (безопасность)
2. Обновляет статус заказа на "paid"
3. Выдает доступ к Telegram каналу
4. Отправляет уведомление клиенту

### Шаг 5: Выдача доступа

Система автоматически:
1. Добавляет пользователя в Telegram канал (через бота)
2. Создает запись в таблице Accesses
3. Устанавливает дату истечения доступа
4. Отправляет клиенту email с инвайт-ссылкой

## Интеграции

### 1. FreedomPay (Платежная система)

**Что это:** Казахстанская платежная система для приема онлайн-платежей.

**Поддерживает:**
- Карты Visa/Mastercard
- Kaspi, Halyk Bank
- Электронные кошельки

**Что нужно:**
- Merchant ID (выдает FreedomPay)
- Secret Key (секретный ключ)
- Настроенный webhook URL

**Режимы:**
- Тестовый (`TESTING_MODE=1`) - для проверки
- Боевой (`TESTING_MODE=0`) - для реальных платежей

### 2. Telegram (Управление каналами)

**Что это:** Telegram Bot для автоматического добавления пользователей в каналы.

**Что нужно:**
1. Создать бота через @BotFather
2. Получить токен бота
3. Добавить бота в канал как администратора
4. Дать боту права на добавление участников

**Возможности:**
- Автоматическое добавление в канал по username или ID
- Генерация инвайт-ссылок
- Уведомления о новых подписках

## Админ-панель

### Доступ к админке

**URL:** `https://ваш-домен.vercel.app/api/admin/login`

**Логин по умолчанию:**
- Username: `admin`
- Password: смотрите в переменных окружения

### Что можно делать

#### 1. Просмотр статистики (`/api/admin/stats`)

```json
{
  "total_revenue": 150000,
  "total_orders": 30,
  "paid_orders": 28,
  "active_accesses": 25,
  "pending_orders": 2
}
```

#### 2. Управление заказами (`/api/admin/orders`)

- Посмотреть все заказы
- Отфильтровать по статусу
- Посмотреть детали конкретного заказа
- Узнать кто оплатил, когда, на какую сумму

#### 3. Управление тарифами (`/api/admin/plans`)

- Создать новый тариф
- Изменить цену
- Обновить описание
- Деактивировать тариф (клиенты его не увидят)
- Привязать к определенному Telegram каналу

#### 4. Управление доступами (`/api/admin/accesses`)

- Посмотреть все активные доступы
- Отозвать доступ (если нужно заблокировать пользователя)
- Посмотреть когда истекает доступ

### Безопасность админки

- Авторизация через JWT токены
- Токен действует ограниченное время
- Пароль хранится в зашифрованном виде (bcrypt)
- Все запросы логируются

## Технологии

### Backend

- **Node.js + TypeScript** - современный JavaScript с типизацией
- **Express 5** - веб-фреймворк для API
- **Prisma 7** - ORM для работы с базой данных
- **Zod** - валидация входящих данных

### База данных

- **PostgreSQL** (через Neon) - надежная реляционная БД
- **SQLite** - опция для локальной разработки

### Безопасность

- **JWT** - токены для авторизации
- **bcrypt** - шифрование паролей
- **Helmet** - защита от типичных веб-уязвимостей
- **CORS** - контроль доступа к API

### Хостинг

- **Vercel** - облачный хостинг с автоматическим деплоем
- **Neon** - облачная PostgreSQL база данных

## Мониторинг и логи

### Проверка работоспособности

Эндпоинт для проверки что система работает:

```
GET /api/health
```

Ответ: `{"status":"ok"}`

1. **Vercel Dashboard**
   - Зайдите в проект

   - Видны все запросы и ошибки

2. **Prisma Studio**

   - Посмотрите все данные в БД

### Что логируется

- Все HTTP запросы (method, URL, status, время)
- Ошибки с полным стектрейсом
- Webhook'и от FreedomPay
- Создание заказов и выдача доступов

## Частые вопросы

### Можно ли продавать доступ к нескольким каналам?

Да! При создании тарифа укажите ID нужного канала. Можно создать разные тарифы для разных каналов.

### Что если клиент не получил доступ?

1. Проверьте статус заказа в админке
2. Посмотрите логи в Vercel
3. Убедитесь что Telegram бот работает
4. Можно вручную отправить инвайт-ссылку

### Можно ли сделать возврат средств?

Технически - да, но нужно:
1. Отозвать доступ через админку
2. Оформить возврат через FreedomPay (вручную)

### Что если клиент хочет продлить доступ?

Клиент просто покупает новый тариф. Система автоматически продлит доступ.

### Безопасны ли платежи?

Да! Система использует:
- HTTPS (обязательно)
- Проверку подписей webhook
- Токенизацию платежей (карты не хранятся)
- PCI DSS compliance (через FreedomPay)
